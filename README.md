## 🇬🇧 English

Welcome to the source code of my personal portfolio. This website is a digital showcase of my work as a **"Fotografante & Videocreatore"** (Photographer & Video Creator), blending my passion for visual arts with modern web development.

### 🌟 About the Project
* **Shooting. Create. Passion.**
* Features dedicated sections for **Projects** (like *Rigolizia Mon Amour*, *Fragile*) and **Photos** (like *Agriturismo Scardaci*, *Cars*).
* Designed to say: *CREATE • DESIGN • BUILD • IMAGINE*

### 🛠️ Tech Stack
This platform is built for speed and performance using modern web technologies:
* **Framework:** Next.js (v16+)
* **Architecture:** React Server Components & Static Site Generation
* **Deployment:** Vercel
